## 🤖 **OPCIÓN 6: Respuestas Predefinidas (FAQ)**

**Usuario:** "Ya probé eso y sigue sin funcionar"
```
Entiendo. Probá esto entonces:
1. Desinstalá la app completamente
2. Reiniciá tu teléfono
3. Instalá la app de nuevo desde la tienda
4. Ingresá con tu usuario

Si aún así no funciona, necesito que me digas:
- ¿Qué modelo de teléfono tenés?
- ¿Te aparece algún otro mensaje de error además de "Error al obtener citas"?
```

---

**Usuario:** "No sé dónde está la configuración de apps"
```
Para encontrar la configuración:

ANDROID:
1. Buscá el ícono de "Ajustes" o "Configuración" (⚙️) en tu teléfono
2. Tocalo
3. Buscá la opción que dice "Apps" o "Aplicaciones"
4. Ahí vas a ver todas las apps instaladas
5. Buscá "Strupeni Técnicos" y tocala

iPhone:
1. Abrí "Ajustes" (⚙️)
2. Andá a "General"
3. Tocá "Almacenamiento del iPhone"
4. Buscá "Strupeni Técnicos" en la lista
```

---

**Usuario:** "¿Voy a perder mis datos si borro la app?"
```
No te preocupes, NO vas a perder nada importante:
✅ Tus trabajos/citas están guardados en el servidor
✅ Tu usuario y contraseña siguen siendo los mismos
✅ Cuando vuelvas a ingresar, se va a sincronizar todo

Lo único que vas a tener que hacer es volver a ingresar 
tu usuario y contraseña cuando abras la app.
```

---

**Usuario:** "No tengo espacio para reinstalar"
```
Entiendo. Antes de reinstalar, probá lo siguiente:
1. Andá a Configuración → Almacenamiento
2. Verificá cuánto espacio libre tenés
3. Si es menos de 200 MB, borrá:
   - Fotos/videos viejos (podés hacer backup en Google Photos primero)
   - Apps que no usás
   - Descargas

Una vez que liberaste espacio, volvé a probar borrar 
datos de la app como te expliqué antes.
```

---

**Usuario:** "Me dice que no tengo internet pero tengo WiFi"
```
Probá esto:
1. Desactivá el WiFi
2. Activá los datos móviles (4G/5G)
3. Abrí la app y probá cargar las citas

Si funciona con datos móviles pero NO con WiFi:
→ El problema es tu red WiFi o firewall
→ Probá reiniciar el router
→ O usá datos móviles mientras tanto

Avisame qué pasó.
```

---

**Usuario:** "Probé todo y nada funciona"
```
OK, en ese caso necesito que me pases:
1. Modelo de tu teléfono (ej: Samsung Galaxy A52)
2. Versión de Android o iOS (Configuración → Acerca del teléfono → Versión)
3. Cuándo empezó el problema (hoy, ayer, hace una semana)
4. Si te pasa solo con las citas o también con otras partes de la app
5. Si podés, enviame una captura de pantalla del error

Con esa info voy a poder ayudarte mejor.
```
